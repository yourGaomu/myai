    Quick Start

    三条命令，
    跑起来

    本地直接聊天只需要一条命令；需要手机控制时，再启动 Relay 和 Agent。

    myai chat终端里直接对话
    myai relay启动手机与 Agent 之间的中继
    myai agent启动 PC Agent 并连接 Relay
    myai skill列出、搜索、安装 Skill
    myai sandbox doctorOpenSandbox 冒烟测试
    # 查看全部命令
go run . help

# 在终端里直接和 Agent 对话
go run . chat
    # 启动 Relay，绑定 Agent 身份与 token
go run . relay --addr 0.0.0.0:18080 \
  --agent-token "replace-with-a-strong-token" \
  --agent-user local --agent-device pc-local
    # 启动 PC Agent，选择手机端可浏览的工作区
go run . agent --server ws://127.0.0.1:18080/ws/agent \
  --relay-token "replace-with-a-strong-token" \
  --user local --device pc-local \
  --workspace D:\Go_All\myai
