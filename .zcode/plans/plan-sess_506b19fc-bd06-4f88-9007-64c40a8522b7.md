## Context

修复此前审查中的 5 项 P1。沿用现有 MCP 管理器、插件热重载、Agent 会话附件查询和短链 MCP 文件协议。通过本地回归验证授权撤销、重新授权、附件准入和上传恢复。

## 实现

1. **让插件撤销和禁用独立生效。** 在 `core/plugin/manager.go`、`core/plugin/trust.go` 和 `core/trust` 记录各运行时实际使用的批准。重载前检查已发布插件的批准状态，先撤下已撤销的插件，再构建新目录。禁用时校验并原子更新目标 manifest，独立移除该插件。使用现有 `BeginReload` 和 `Retire` 管理目录与客户端生命周期，并在工具调用入口检查共享禁用状态和原批准，覆盖旧会话持有的快照以及 CLI 已撤销但 Agent 尚未重载的情况。允许已经提交的调用收尾。
2. **按实际 MCP 工具身份记住许可。** 从执行器已经解析出的工具对象提取内部身份，经 `PermissionRequest`、前台流和后台事件传给 `core/remote/agent`。身份绑定来源命名空间、服务声明、连接目标、原始工具名和权限类别。MCP 的两种会话记忆范围均按该身份匹配。收到较早的审批回复时，仍只记录当时请求的身份。保留本地工具的既有授权范围和逐次确认规则。
3. **统一 HTTP MCP 的连接批准和错误脱敏。** 在 `core/mcp/{client,http_client}.go`、`core/config` 和 `core/cmd/trust.go` 复用现有信任机制。运行时和 trust CLI 使用同一配置来源与声明指纹。连接前批准确定的目标和声明，批准后才读取请求头引用的环境值。显式服务与自动合并的 `short_links` 均纳入检查，环境中的请求头值轮换无需重新批准，端点或声明变化需要重新批准。部署已使用 HTTP MCP 的 Agent 时，需要在 Agent 的工作区与信任存储下批准现有声明。错误出口只返回安全的阶段信息、有限状态或错误分类，并保留取消和超时语义。原始 stderr、服务端错误内容和底层请求细节留在对外错误边界之外，成功工具结果继续按既有契约处理。
4. **在手机知识库导入前验证素材归属。** 在 `core/remote/agent/knowledge_handlers.go` 复用 `LookupSessionAsset` 与现有会话生命周期约束。检查配对身份、请求会话和素材 ID，再进入下载、持久化和索引。覆盖刚上传且等待持久化的附件，同时对其他会话、无有效附件记录、已失效的待写入记录以及缺少校验能力的请求拒绝准入。遵循当前会话清理对已持久化附件的语义。
5. **修复上传回执清理和后端取消。** 在 `core/adapter/files/shortlinks/{upload,receipts}.go`、`core/port/files` 和 `core/remote/uploads/receiver.go` 处理确认未创建、确认过期或终结，以及结果不确定这几种状态。确认终结后释放租约和回收容量。对未知结果按原幂等键和已知会话状态进行有界恢复，可能已提交的完成操作保留恢复记录并禁止重新开始。手机取消继续校验完整上传归属，等当前 worker 退出后用内部键定位回执，在同一租约上调用现有 `cancel_asset_upload`。完成先发生时保留资产并继续记录，取消先成功时释放后端配额，清理失败保留可重试状态。通过本地独立短链后端契约测试核对状态语义。

## 验证

- 本地回归覆盖无关重载失败时撤销和禁用仍生效、旧快照的新调用受限、健康的其他插件保持可用、MCP 前台和后台许可对真实工具身份生效，以及 HTTP 批准前不建立连接、CLI 和运行时指纹一致、错误边界不传播模拟敏感标记。
- 使用模拟短链 MCP 和现有手机上传集成测试覆盖正常导入、无归属请求在零下载时被拒绝、失败和过期回执回收、完成结果丢失后安全恢复、取消和完成的并发顺序。
- 运行 Go 定向及全量回归，复跑移动端 TypeScript 检查和回归，确认此前的 MCP 列表与热重载测试继续通过。
