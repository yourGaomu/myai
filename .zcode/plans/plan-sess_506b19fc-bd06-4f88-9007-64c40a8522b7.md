## Context

将 MyAI 的短链接、文件分享、手机上传和知识库文件导入统一迁移到外部短链 MCP，移除旧 UrlShortener 运行依赖及兼容分支。

当前普通短链已接 MCP，但文件工具和手机上传仍连接旧 HTTP 服务。已核对独立项目 `D:/Go_All/short_links/back`：它提供 7 MiB 小文件上传和 32 MiB 分片上传，但缺少素材查询、签发下载地址、对已上传素材创建分享链接的 MCP 工具。完整迁移需要修改 **MyAI 与 short_links/back 两个项目**。

## 1. 补齐短链后端 MCP 文件接口

修改 `short_links/back/internal/transport/httpapi/mcp_routes.go` 及测试，复用已有业务服务：

- `get_asset_info(assetId)`：调用 `Assets.Get` 返回元数据。
- `get_asset_download_url(assetId)`：调用 `Assets.Content` 签发短期下载地址，不消耗公开短链访问次数。
- `create_asset_shortlink(assetId, title?, expiresAt?, maxVisits?)`：调用 `Links.Create`，支持分片上传完成后分享。
- 文件结果提供明确的 `structuredContent`，MyAI 不解析中文展示文本。
- 保持现有账户、业务范围、权限及删除状态检查。

文件字节通过 MCP 签发的地址下载；解析继续复用 MyAI 的处理器。

## 2. 用统一 MCP 适配器替换旧客户端

主要涉及 `core/mcp/manager.go`、`core/mcp/client.go`、`core/App.go`，以及新增文件 port、service 和 adapter。

- 复用 `Client.CallTool` 原始结果，以服务器身份和原始工具名调用。
- 复用 `RegisterTools.Snapshot/Retire` 租约，保护重载期间正在执行的传输。
- 文件由宿主程序读取、编码和分片；字节及 Base64 不进入模型上下文、审批参数或工具历史。
- 使用上传会话、幂等键和状态查询处理重试；完成或建链结果不明时不盲目重复创建。
- 下载执行大小、时长和重定向检查，不向对象地址发送 MCP 密钥，不回显签名 URL。
- MCP 未配置、不可达或接口缺失时明确报错，不回退到旧服务。

## 3. 迁移工具、资源记录与知识库

主要涉及 `core/tool/local/share_file.go`、`read_asset.go`、`core/adapter/documentsource/asset/source.go`、工具资源提取器和 App 装配。

- 保留 `share_file`、`read_asset` 作为用户功能名称，内部完全改为 MCP；删除旧 REST 实现和类型依赖。
- 保留受保护路径拒绝、普通文件检查和发布审批；同步处理原生 MCP 发布工具，避免换工具名绕过审批。
- 读取和知识库导入使用 `asset_id`，经 MCP 获取元数据及下载地址，再进入现有解析、原件保存和索引流程。
- 将有用的解析代码迁出 `core/asset`；不额外扩展原先未支持的文档格式。
- 统一资源元数据，贯通聊天资源卡片、会话资源列表、子代理事件及持久化。
- 调整初始化依赖，知识库服务不再依赖旧 assetClient。

## 4. 手机上传走已认证的 Agent/Relay

主要涉及 Go/TypeScript protocol、`core/remote/agent`、`core/remote/relay/server.go`、`mobile/src/utils/assetUpload.ts`、文件/知识库 hooks 和设置 props。

- 增加受限的开始、传块、状态、完成和取消上传操作，由 Agent 调用 MCP，不暴露任意 MCP 调用代理。
- 手机使用现有配对身份，机器密钥只留在 Agent。
- 手机采用 256 KiB 小块和逐块确认，上传报文上限 512 KiB，初始单文件上限 50 MiB；限制活动上传数及暂存字节，后端更严格的配额继续生效。
- Agent 私有暂存并按后端要求发送 32 MiB MCP 分片；完成、取消、超时和退出时清理。
- 上传绑定身份、会话和请求 ID，处理断线、取消、乱序及不确定完成，等待业务结果。
- 聊天附件和知识库导入携带 asset ID；移除手机 Asset 地址和 Asset API Key 设置。
- 避免自动预览消耗一次性或限次分享链接。
- 保留当前已有移动端界面修改，只修改迁移相关字段与调用链。

## 5. 清理旧代码和部署配置

- 删除旧 `core/asset` HTTP 客户端、旧配置及兼容分支；迁移仍有用的解析、安全和持久化测试。
- 检查后逐项移除已跟踪的 `UrlShortener` 子模块和 `Dockerfile.url-shortener`；保留可能存在的私有本地配置及数据。
- 从 Compose、配置示例和注释模板移除 `ASSET_*`、`URL_SHORTENER_*`、`MYAI_URL_SHORTENER_IMAGE` 和旧 `asset:`。
- 备份并更新本地 `.env`：短链只使用 `SHORT_LINKS_MCP_URL`、`SHORT_LINKS_API_KEY`。真实 MCP 地址与后台签发的 Key 未提供时标明待配置，不挪用旧附件密钥。
- 保留知识库所需的 `RAG_MINIO_*`。
- 更新 MCP 接入、部署、移动端和架构文档；历史评估与修复记录保留历史语境。

- MyAI：仅配置 MCP 时的分享、读取、手机上传、知识库导入和资源持久化；确认不调用旧 HTTP 接口。

- 运行定向及全量 Go 测试、build/vet、Linux 交叉构建和移动端 TypeScript 检查。
