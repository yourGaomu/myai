# 图像生成与编辑

## 工具使用

- 必须使用 `generate_image`，不要伪造生成结果或把 API Key 放入提示词。
- 先检查工具描述中的可用模型；用户指定模型时传 `model_id`，否则使用默认模型。
- 生成前把提示词整理成明确的主体、动作、构图/景别、场景、光线、色彩/材质和风格约束。保留用户指定的文字、品牌和构图要求；不要擅自添加文字。
- 图生图时将当前会话的图片资源 ID（`ast_...` / `asset:ast_...`）或工作区相对路径放入 `reference_images`，并在提示词中说明保留什么、修改什么。只有需要遮罩编辑时才使用 `mask_image`。
- 透明贴纸或图标优先指定 `background: "transparent"`、`output_format: "png"`。静态输出支持 PNG/JPEG/WebP；动图预览能力不表示上游模型可生成 GIF。
- 尺寸、比例和质量参数只在工具 Schema 支持的范围内传递；模型不支持某项能力时，说明限制，不要声称已应用。

## 保存与回复

- 默认输出保存到 `.myai/generated/`。用户明确要求位置时才指定 `output_path`；遵循工具的路径审批和保护规则，不覆盖敏感文件。
- 生成成功后引用工具返回的 `markdown_embed`（`![caption](asset:ASSET_ID)`），让图片在聊天中显示。可简短说明模型和主要处理结果。
- 如果生成失败，说明失败信息和可尝试的替代方案；不要输出虚构图片链接。
