Quickstart Deployment

2 分钟极速接入生产环境

支持 Docker Compose 一键拉起完整集群，或通过 Go CLI 单二进制启动。

一键拉起高可用 Relay 中继与 Agent 容器网络：

$ docker compose -f compose.prod.yaml up -d
在根目录 .env 配置 MYAI_RELAY_TOKEN 与大模型 API Key 即可。

1. 启动轻量高并发 Relay 中继守护进程 (延迟 14ms):

$ go run . relay --addr 0.0.0.0:18080 --agent-token "secret-token"

2. 挂载本地代码库启动 PC Agent:

$ go run . agent --server ws://127.0.0.1:18080/ws/agent --workspace .

在手机端打开 MyAI App，输入中继地址与设备凭据完成秒级配对：

ws://你的服务器公网IP:18080/ws/agent (支持 TLS wss://)
FAQ

常见问题答疑

关于安全性、开源协议与跨平台支持的权威解答。

❓ MyAI 与 GitHub Copilot / Cursor 的根本区别是什么？ ›
移动掌控与全域自主：传统 Copilot 仅限于电脑桌面 IDE 内的代码补全；而 MyAI 是完整的全域自主智能体系统，首创通过手机端随时随地调度子代理群、审查 Diff 与 Git 快照回滚。无论身处地铁、咖啡馆还是在床上，都能随时掌控代码库。
🔒 我的私有代码会被上传到云端或用于模型训练吗？ ›
绝对不会：MyAI 秉持 100% 源码本地驻留架构。代码文件只在您的宿主机开发机读写，绝不经过任何第三方中间服务器存储，彻底杜绝源码泄露风险。
💰 MyAI 是免费开源的吗？有商业限制吗？ ›
完全开源免费：核心框架基于 Apache 2.0 协议开源，完全支持自由部署和二开。您只需配置自己的大模型 API Key（OpenAI / Anthropic / DeepSeek / 本地 Ollama 均可）。
📱 支持 iOS 吗？只能用 Android？ ›
全平台支持：Android 端为 React Native 原生打包；iOS 端支持通过移动 Safari“添加到主屏幕”作为 PWA WebApp 体验，功能完全一致。
📱 手机端打字时输入框真的不会遮挡上面的对话内容吗？ ›
移动原生防遮挡：我们针对移动端进行了像素级视口适配（支持虚拟键盘智能顶起与视口滚动避让）。输入框聚焦弹起键盘时，历史对话自动无缝上推，100% 保持视野开阔。
