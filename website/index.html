源码 100% 本地驻留
代码文件仅在您的宿主机开发机读写，绝不上传第三方云端，完全杜绝源码泄露。

Developer Quickstart

2 分钟极速接入生产环境

单二进制即开即用，或通过 Docker Compose 一键拉起生产集群。

🐳 生产级 Docker Compose 一键启动
推荐部署
拉起高可用 Relay 中继与 Agent 容器网络：
$ docker compose -f compose.prod.yaml up -d
在 .env 配置 MYAI_RELAY_TOKEN 与大模型 API 密钥即可。
⚡ 原生 Go CLI 单二进制启动
开发调试
1. 启动轻量高并发 Relay 中继 (延迟 14ms):
$ go run . relay --addr 0.0.0.0:18080 --agent-token "secret"
2. 挂载本地代码库启动 Core Agent:
$ go run . agent --server ws://relay:18080/ws/agent --workspace .
Frequently Asked Questions

常见问题答疑

💰 MyAI 是免费开源的吗？有商业限制吗？ ›
完全开源免费：核心框架基于 Apache 2.0 协议开源，完全支持自由部署和二开。您只需配置自己的大模型 API Key（OpenAI / Anthropic / DeepSeek / 本地 Ollama 均可）。
📱 手机端打字真的不会遮挡对话记录吗？ ›
移动原生防遮挡：我们针对移动端进行了像素级视口适配（支持虚拟键盘智能顶起与视口滚动避让）。输入框聚焦弹起键盘时，历史对话自动无缝上推，100% 保持视野开阔。
🔒 我的私有代码会被上传到云端或者被用于模型训练吗？ ›
绝对不会：MyAI 采用只读沙箱和本地驻留架构。代码文件只在您的工作机本地读写执行，绝不经过任何第三方中间服务器存储，杜绝源码泄露。
